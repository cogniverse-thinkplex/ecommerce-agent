# A+C 认证界面改造设计

## 目标

将登录、注册和首次改密页面统一改造成面向真实客户的认证入口：采用 Notion 式简洁表单与现代电商履约场景视觉，不向用户解释账户角色或后台分流规则。

## 设计选择

- 已选择 A+C：极简表单结构与真实电商服务视觉结合。
- 桌面端采用视觉区与认证区双栏；移动端将视觉区压缩为顶部品牌区域，表单保持完整可用。
- 使用项目内本地位图，不依赖外部图片服务；图片不含文字、商标或人物面部。
- 页面使用白色、墨色、珊瑚红和少量草绿色，避免旧版大面积深绿色与单一色调。
- 登录页仅呈现品牌、欢迎语和必要字段；用户角色由现有后端登录响应决定并自动跳转。

## 交互

- 三个页面共用认证壳、字段样式、错误反馈与提交状态。
- 密码字段提供可访问的显示/隐藏按钮，提交按钮显示明确的处理中状态。
- 保留浏览器自动填充语义、键盘焦点、错误 `role=alert` 与移动端布局。
- 注册页说明密码规则；首次改密页说明当前操作目的，但不暴露内部权限机制。

## 非目标

- 不改变认证 API、角色模型、Session Cookie 或登录后的路由规则。
- 不增加第三方登录、忘记密码或营销落地页。

## 验收

- 页面不再出现“普通用户进入客服中心，开发人员进入工程观测控制台”等内部说明。
- 登录、注册、改密三页样式统一；登录与注册 API 行为保持不变。
- 桌面与移动视口无溢出、遮挡，图片加载失败时仍可完成认证。
