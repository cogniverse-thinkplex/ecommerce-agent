# 客户界面精简与美化设计

## 目标

让客服中心更接近日常客服产品：减少工程说明，强化对话、会话整理、人工服务和账户入口；同时把账户页整理为可信的资料与安全设置页面。

## 已选方案

采用克制的产品化改造，不增加无法真实执行的配置。删除底部权限说明条，将“转人工”移入顶栏；空对话提供常用问题快捷入口。账户页保留显示姓名、只读登录邮箱、购买账户关联状态和修改密码，并允许客户直接读取、编辑自己购买账户的默认收货地址。保存地址即为明确提交，已有订单的配送地址不随默认地址变化。

## 约束

- 不改变 Agent、MCP、确认门禁、人工工单和数据库结构。
- 不伪造手机号、邮箱换绑、通知设置或地址直改能力。
- 桌面与移动端不得横向溢出；控件保持可访问名称。
- 客服页面不展示策略、工具、成本或权限实现细节。

## 验证

- 静态测试锁定权限条删除、顶栏转人工、快捷问题和账户页信息结构。
- 浏览器验证桌面与移动布局、快捷问题填入输入框、转人工入口和账户页。
- 完整后端回归与产品栈验收通过。
