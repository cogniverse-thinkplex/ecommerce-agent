# Documentation Refresh Implementation Plan

## Task 1：校准项目事实

- 对照后端模块、静态页面、启动脚本、环境变量和测试，建立当前能力清单。
- 把未实现技术从“当前架构”移动到“可选演进”。

## Task 2：重写 GitHub 首页

- 重写根 `README.md`。
- 添加产品地图、架构图、执行时序图、能力矩阵和快速启动。
- 明确演示数据、账号、安全注意事项、测试与许可边界。

## Task 3：建立课程体系

- 创建 `docs/agent-course/README.md` 课程主页。
- 创建十个按依赖递进的课时 README。
- 每课引用真实代码路径和验证命令。

## Task 4：验证

- 检查 Markdown 内部链接。
- 检查课程文件齐全、代码块闭合。
- 运行后端测试，确认纯文档改动没有影响产品。
- 复核 README 的启动命令和当前默认配置。
